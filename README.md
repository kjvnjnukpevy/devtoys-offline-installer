# DevToys — Free Offline Installer

![Category](https://img.shields.io/badge/Developer_Utility-blue?style=flat-square)

## About

DevToys is a free, open-source Swiss Army knife for developers on Windows and macOS. Convert data formats (JSON, YAML, XML), encode and decode Base64, JWT, and URLs, format and minify code, generate UUIDs, work with regular expressions, and perform hash computations — all in one local tool. DevToys eliminates trips to online converter websites by providing everything locally.

## Common Problems & Limitations

- **Platform Availability** — macOS version newer and less feature-complete than Windows version
- **Feature Depth** — Individual tools less powerful than dedicated single-purpose utilities
- **No Command Line** — GUI-only; not scriptable for batch processing
- **Offline Focus** — Designed for local use; no cloud or sharing features
